# Vibrations Video Productions — website

A static, single-page site. No build step: open `index.html` in a browser, or host the folder on any static host (GitHub Pages, Netlify, Vercel).

## Editing

- **Contact email** — `CONTACT_EMAIL` at the top of `script.js`.
- **Photos** — files live in `assets/photos/`. Each photo on the page is a `<button class="shot">` in `index.html`; copy one to add another.
- **Services and copy** — plain text in `index.html`.

Colours and fonts are variables at the top of `styles.css`.
